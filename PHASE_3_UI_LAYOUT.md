## Data Flow During Interaction

### Step 1: Audio Upload

```
User selects WAV file
        ↓
    Wav component
        ↓
   BPM Detection
        ↓
Audio Features Extracted
        ↓
    App.jsx State Updated
```

### Step 2: Kyōga Analysis Triggered

```
Audio Features → interpretMood() → Mood Vector (9D)
                    ↓
             resonateColor() → Color Palette
                    ↓
             harmonizeTemplate() × N → Scores
                    ↓
           Update App State & Re-render
```

### Step 3: User Selects Template

```
Click Template
        ↓
onSelectTemplate() called
        ↓
generateParameterSuggestions()
        ↓
tuneParameters() API
        ↓
Display suggestions with Apply buttons
```

### Step 4: User Applies Suggestions

```
Click [✓ Apply] button
        ↓
acceptParameterSuggestion()
        ↓
Update config state
        ↓
Parameter field re-renders with new value
```

## Color Coding

| Alert Type | Color  | Use Case                  |
| ---------- | ------ | ------------------------- |
| Info       | Blue   | Mood Analysis (9D vector) |
| Success    | Green  | Color Palette Display     |
| Warning    | Yellow | Template Recommendations  |
| Secondary  | Gray   | Parameter Suggestions     |

## Responsive Design

All sections use Bootstrap grid system:

- **Desktop** (>768px): Full width tables with multiple columns
- **Tablet** (576-768px): Wrapped tables with stacked rows
- **Mobile** (<576px): Vertical layouts with condensed displays

## Accessibility Features

- Progress bars with aria labels
- Confidence badges for clarity
- Semantic HTML table structure
- Color contrast meets WCAG AA standards
- Keyboard navigation for all buttons

## Animation & Interactivity

- Smooth progress bar fills (CSS transitions)
- Color swatches with subtle shadows
- Hover states on Apply buttons
- Button feedback on click
- Loading states for async operations (kyogaAnalyzing flag)
